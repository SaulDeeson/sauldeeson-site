# sauldeeson.com

https://sauldeeson.com/

Personal site. The work page brings together some of the player-facing projects I worked on at Wargaming and demos of the tools I built for my team.

The site lives in `public/` and deploys to Cloudflare Workers from `main`. Project entries are in `public/assets/projects.js`, and the recordings are hosted on GitHub Pages from `sauldeeson-media`.

To run it locally, use `python -m http.server 8000 --directory public` and open `http://localhost:8000`.
